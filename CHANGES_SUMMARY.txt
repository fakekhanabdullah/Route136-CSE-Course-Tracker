ROUTE136 — WHAT WAS UPDATED & HOW IT WAS BEFORE (CHANGE SUMMARY)
================================================================================

1. SETUP WIZARD OVERHAUL: TIMELINE FIRST, FLEXIBLE RS & LANDING PAGE AESTHETIC
--------------------------------------------------------------------------------
- BEFORE:
  * Step 1 asked for 1st Semester Entry Pathway first, while Current Semester,
    Starting Intake, and RS were buried in Step 2.
  * "When do you attend RS?" only offered 3 fixed buttons (3rd, 4th, 5th Sem)
    with no way to enter another semester number or choose "Not Sure Yet".
  * Step 2 also showed a confusing 4-case "Stream 1 Status Prior to RS" module.
- NOW:
  * Redesigned the Setup Wizard to match the Landing Page Vercel Developer
    Platform aesthetic (36px structural grid, radial blue spotlight, macOS
    window chrome header `route136.app/setup`, and 3-column step indicator pills).
  * Step 1 (First Popup) is now "Current Semester, Intake & RS":
      - Select Current Semester (1st – 12th Semester), Starting Term, and Year.
      - "When do you attend RS?" includes quick presets (3rd, 4th, 5th, or
        "Not Sure Yet") PLUS a custom semester number dropdown (2nd – 12th
        Semester or "Not Sure / Decide Later").
      - Removed the confusing "Stream 1 Status Prior to RS" module entirely.
  * Step 2 is a clean 2-card "1st Semester Starting Pathway" selector with
    `GraduationCap` (Direct Credit) and `Compass` (Non-Credit Foundation) icons.
  * Step 3 is an interactive "Populate Your Semesters (1st -> Current)" screen:
      - If you have reached or completed your RS semester, the RS card is
        pre-populated with EMB101, HUM103, and BNG103, and offers inline buttons
        right on the RS card to choose "+ ENG102" or "+ BU201" as your 4th RS
        course.
      - Removed the legacy `useEffect` that overwrote `BU201` back to `ENG102`.

2. MULTI-SEMESTER ADD COURSES + IN-BATCH RETAKE / REPEAT COURSE PROMPT
--------------------------------------------------------------------------------
- BEFORE:
  * Adding courses to multiple semesters required reopening the modal or
    changing dropdowns row by row, and you could not queue a repeated course
    across two different semesters in a single session.
- NOW:
  * Redesigned `AddCoursesModal.tsx` with a **Horizontal Multi-Semester Tab
    Switcher** (`Sem 1`, `Sem 2`, `RS`, `Sem 4`, etc.).
  * **Repeat Course in One Go**: If you select a course in one semester tab and
    then switch to another semester tab and click that same course again (or
    click a course already enrolled in an earlier semester), an inline prompt
    asks: *"Repeat [CODE] in [Semester]? Do you want to repeat (retake) it or
    move it?"* Clicking **"Yes, Repeat Course"** queues the second attempt with
    a `RETAKE` badge in the same session!

--------------------------------------------------------------------------------
- BEFORE:
  * There was no dedicated visual page showing all CSE & MNS prerequisite
    chains and how many courses remained in each chain.
- NOW:
  * Added `/flow charts and updated degree plan/` to `.gitignore`.
  * Built `PrereqChainsModal.tsx`, accessible from the left sidebar under
    Utilities (**`Pre-req Chain`**) and the top workspace bar:
      1) **Programming, Algorithms & Systems Backbone** (`CSE110` -> `CSE111` ->
         `CSE220` -> `CSE221` -> `CSE321/370/331/422` -> `CSE420/470/471` -> `CSE400`)
      2) **MNS Calculus, Linear Algebra & Applied Computing Chain** (`MAT110` ->
         `MAT120` -> `MAT216` -> `MAT215 / CSE330 / CSE423`)
      3) **Physics, Electronics, Architecture & Robotics Chain** (`PHY111` ->
         `PHY112` -> `CSE250` -> `CSE251` -> `CSE260/350` -> `CSE340/460/461` ->
         `CSE341` -> `CSE360`)
      4) **Data Communications & Computer Networks Chain** (`CSE320` -> `CSE421`)
      5) **BIL English & Technical Communication Chain** (`ENG101` -> `ENG102`)
      6) **CSE Major Elective Prerequisite Gates** (all 23 gated electives)
  * Each chain displays a live **"X / Y Completed • Z Left (N%)"** progress bar,
    highlights **"Ready Next"** unlocked courses, shows Hard (`HP`) & Soft (`SP`)
    prerequisites on every node, and includes an interactive **Course Dependency
    Inspector** when you click any course box.
